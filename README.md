# Юридический квалификатор киберпреступлений

Учебная экспертная система (СРС «Правовые аспекты киберпреступлений»).
Пользователь отмечает признаки инцидента, программа по правилам выводит
статьи УК РК, квалифицирующие признаки и рекомендации по сбору доказательств.

## Запуск
```
python app.py          # графический интерфейс (Tkinter, нужен Python 3.8+)
python test_rules.py   # проверка правил
```

## Структура
- `rules.py` - база знаний и логика вывода (без GUI)
- `app.py` - интерфейс
- `test_rules.py` - тесты трёх сценариев и граничных случаев

> Заключение носит учебный характер. Номера статей и санкции сверяйте с adilet.zan.kz.
